# Dynamic Predator-Prey Simulation

A dynamic simulation of predator–prey interactions among lions, foxes, and rabbits developed in Java. This project models population dynamics in a grid-based environment using object-oriented design and a custom graphical interface to visualize real-time changes.

## Overview

Originally developed as a software engineering project at Rowan College at Burlington County (January–May 2021), this simulation models the interactions between predator and prey species. It leverages object-oriented principles to keep the code modular and extensible. In this updated version, the simulation has been enhanced to provide a smoother GUI experience and clearer real-time statistics on population trends.

## Features

- **Dynamic Simulation:** Real-time visualization of predator and prey interactions on a grid.
- **Graphical User Interface (GUI):** Custom interface displaying simulation state, population counts, and trends.
- **Modular Design:** Clear class hierarchies for animals (Lion, Fox, Rabbit) and environmental components (Field, FieldStats).
- **Extensible Architecture:** Easily add new species or modify existing behaviors.
- **Statistical Insights:** Monitors and reports population changes and trends as the simulation runs.

## Prerequisites

- **Java Development Kit (JDK):** Version 8 or higher.
- **Integrated Development Environment (IDE):** Recommended (e.g., IntelliJ IDEA, Eclipse, or NetBeans).
- **Build Tools (Optional):** Maven or Gradle for managing dependencies and builds.
